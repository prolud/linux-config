# linux config

this repository contains an easy and automated setup for the apps and tools that i use to work on debian based distributions.

the goal is simple: clone this repository, run the setup, and have everything i need to start working.

## supported distributions

it works well on:

* [x] ubuntu
* [x] linux mint
* [ ] debian? (didn't test it yet)

## updates

some packages need to be updated periodically because they are not always installed through the system package manager.

packages to update periodically:

* netcoredbg
* dotnet
* mongodb-compass
* nvm

## secrets

this repository doesn't have any secrets.

there's nothing hidden here, so don't waste your time looking for something.
